### Completed (plan Day 3: tool registry/dispatcher + error handling)

- `src/agent/tool_registry.py`: the lookup table of tools.
  - `Tool` dataclass: name, description, typed params, function, `writes` flag; `schema()` returns the description in LLM function-calling shape.
  - `ToolRegistry`: `register` (rejects duplicate names), `get`, `names`, `schemas`.
  - `build_registry(store)`: registers 3 read tools - `get_claim`, `get_claim_status`, `calculate_claim` - all taking `claim_id`.
- `src/agent/dispatcher.py`: runs one tool call and always returns a string.
  - Success returns JSON text; any failure returns `Error: ...`, so a bad call never kills the run.
  - `parse_args` accepts a dict or a JSON string; `validate_args` rejects unknown, missing and wrongly typed arguments (exact type check, so `True` is not accepted as an int).
  - Unknown tool names return the list of available tools.
  - Two tiers of errors: expected ones (`ToolArgError`, `StateStoreError`) give a clean message; an unexpected bug inside a tool is caught and reported with its exception type.
  - No `eval` or `getattr` on model output; the model can only choose a name that exists in the registry.
- `tests/test_dispatcher.py`: 18 tests (read tools, JSON-string args, calculate is read-only, unknown tools, bad arguments, missing claim, injection text treated as data, a failing tool does not crash the run, schemas).
- Full run: `python -m pytest -q` -> `37 passed` (4 claim + 5 state store + 10 business rules + 18 dispatcher).

### Design decisions

- `dispatch` returns a string for every outcome. The agent loop (Day 4) can append it directly as the observation.
- `submit_decision` (write tool) is not registered yet; the plan puts it on Day 5. It will map agent decisions (APPROVE/REJECT/ESCALATE) to `ClaimStatus` values (APPROVED/REJECTED/ESCALATED) and return the new status so `get_claim_status` can verify it.
- `calculate_claim` as a tool takes `claim_id` (the plan's contract); the registry loads the claim from the state store and calls the business-rules function.
